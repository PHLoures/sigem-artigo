===========================================================
 SIGEM - COMO EXECUTAR O PROJETO
===========================================================

Toda vez que for usar o sistema, siga esta ordem:


PASSO 1 - Garantir que o banco de dados (MySQL) esta ligado
-------------------------------------------------------------
Abra o Terminal e cole:

brew services start mysql
mysql -u root sigem

(Se ja estiver ligado, ele so avisa "already started" - sem problema.)


PASSO 2 - Ligar o BACKEND (API)
-------------------------------------------------------------
Ainda no Terminal, cole:

cd ~/Documents/sigem-artigo/backend && node src/app.js

Espere aparecer a mensagem:
Servidor SIGEM rodando em http://localhost:3000

NAO FECHE essa aba nem digite mais nada nela.


PASSO 3 - Ligar o FRONTEND (site)
-------------------------------------------------------------
Abra uma NOVA ABA do terminal (atalho: Cmd + T) e cole:

cd ~/Documents/sigem-artigo/frontend && python3 -m http.server 5500

Espere aparecer a mensagem:
Serving HTTP on :: port 5500

NAO FECHE essa aba tambem.


PASSO 4 - Abrir o site no navegador
-------------------------------------------------------------
Abra o Chrome ou Safari e acesse este endereco:

http://localhost:5500/index.html

Essa e a tela de login. Digite seu nome e entre como Convidado.
Depois disso, voce chega no PORTAL, onde escolhe qual sistema
quer acessar (Medicamentos, Leitos, Escalas ou Fila de Cirurgias).


===========================================================
 PARA ENCERRAR
===========================================================
Volte em cada aba do terminal (backend e frontend) e aperte
Ctrl + C para parar os servidores.


===========================================================
 SE ALGO DER ERRADO
===========================================================
- Erro "Address already in use" ao rodar o frontend ou backend:
  significa que ja tem um servidor rodando naquela porta. Pode
  ignorar e so acessar o site normalmente, ou fechar a aba antiga
  antes de abrir outra.

- Pagina abre mas sem estilo bonito (logo gigante, sem cor):
  de um "hard refresh" no navegador: Cmd + Shift + R

- Pagina do dashboard aparece vazia ou com erro vermelho:
  o backend nao esta rodando. Confira o Passo 2.

===========================================================
 PRIMEIRA VEZ RODANDO O PROJETO NUMA MAQUINA NOVA?
===========================================================
Depois de criar o banco "sigem", rode TODOS esses arquivos,
na ordem (dentro da pasta do projeto):

mysql -u root sigem < database/schema.sql
mysql -u root sigem < database/seed.sql
mysql -u root sigem < database/schema_modulos.sql
mysql -u root sigem < database/seed_modulos.sql
